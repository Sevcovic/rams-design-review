Rams Design Review

A Claude skill that checks your design against Dieter Rams' ten principles and tells you which one each mistake breaks.

View on GitHub Download SKILL.md

The principles

  1. 01Innovative
  2. 02Useful
  3. 03Aesthetic
  4. 04Understandable
  5. 05Unobtrusive
  6. 06Honest
  7. 07Long-lasting
  8. 08Thorough down to the last detail
  9. 09Environmentally friendly
  10. 10As little design as possible

How it works

Share the design. A screenshot, a Figma link, a live URL or UI code.

Answer up to four questions. The goal, the users, how finished it is, and what it has to follow. It skips anything the design already answers.

Get the review. A one-line verdict, issues ranked by severity with a concrete fix for each, and a table covering all ten principles. Only real problems are reported.

Sample finding

High · No "today" or "next shift" emphasis
Where
This week's shift list
Problem
All shifts look identical. Nothing shows which one is next.
Breaks
#2 Useful
Fix
Highlight the next shift with a "Today" or "Tomorrow" label and dim past ones.

From a review of a staff scheduling app.

Install

Claude app: download SKILL.md, put it in a folder named rams-design-review, zip it and upload under Settings → Capabilities → Skills.

Claude Code:

mkdir -p ~/.claude/skills/rams-design-review
curl -L https://github.com/Sevcovic/rams-design-review/raw/main/skill/SKILL.md \
  -o ~/.claude/skills/rams-design-review/SKILL.md

Then ask: "Review this with Rams principles" and attach your design.
